# Метрики отчётов

Обновлено: сентябрь 2024.

- **Выручка** — сумма продаж клуба за месяц.
- **Визиты** — количество визитов за месяц.
- **Пробный визит** — визит с типом `trial`.
- **Конверсия пробных** — количество продаж абонементов за месяц, делённое на количество пробных визитов за тот же месяц.
- **Персональные тренировки** — количество тренировок за месяц и выручка по ним.
